---
name: qm-quiz-writing
description: "Create original, source-backed Quiz Master quiz drafts with varied challenges and clear explanations."
---

Consume a brief: audience, language, topic, pack size, knowledge goals, difficulty mix and supported question types. Create a 10-question pilot before large batches; the pilot size is an operating default, not a product limit. Favor an interesting insight or fair misconception over trivia ambiguity.

For each question record draft ID, stem, stable option IDs, intended correct answer, explanation, why each distractor is plausible/wrong, source URL with access date, and estimated difficulty. Use primary factual sources; a generated answer is not evidence. State temporal/geographic qualifications. Do not invent citations, facts, quotations, licensing or measured difficulty.

Default to four choices for new single-choice drafts, while preserving support for 4–6 in the schema/UI. One clearly best answer, parallel options, no accidental length/grammar clues or trick negatives. Multiple choice and text need the approved exact scoring/normalization policy. Mix recall, comparison and application where appropriate. No unsupported new interaction type.

Write original phrasing rather than copying quizzes. Sources support the fact, not permission to reproduce large passages. Use provided media only with documented source/rights; optional generated illustrations are separate tasks, never factual evidence.

Write only the leased draft batch. No direct changes to canonical released packs and no publication. Submit a candidate-facing version without the key plus a private answer/source record to the fact checker for an independent solve, then resolve concrete findings. quizctl/schema validation and editorial acceptance are separate gates. Use the content MCP draft/validate tools when implemented; before that use schema-validated local drafts.
