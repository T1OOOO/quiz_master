# NIKISHOW — Frame 268

Отдельная адаптивная HTML/CSS-страница, без сборки и JavaScript. Откройте `index.html` в браузере или запустите из этой папки `python -m http.server 8094`.

Источник: [Frame 268, страница «Обновления», узел 1:13283](https://www.figma.com/design/OkopTqzd9pO8fYWafNpgbz/?node-id=1-13283). В Figma есть шесть фреймов с таким именем; реализован десктопный блок «С нами комфортно» размером 1600 × 1187 px. На узких экранах карточки расположены в одну колонку.

Шрифты, фон и три значка сохранены локально с сайта https://nikishow.ru. Фон принадлежит общему родительскому разделу исходного макета и адаптирован для отдельной страницы. Для заголовков используется доступный на сайте Bebas Neue Pro Regular с браузерным жирным начертанием; Figma указывает Bebas Neue Pro Exp Rg, 700. Это может давать небольшие отличия метрик текста.

Кнопка «оставить заявку» открывает существующую форму https://nikishow.ru/#form. Эта страница сама не собирает и не отправляет данные. Для интеграции с другой формой замените `href` в `index.html`.

Исходники текущего Flutter/Expo-приложения не затронуты.
