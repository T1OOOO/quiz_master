- Убраны пояснения в скобках из вариантов, подсказки в тексте вопроса, неуместные отвлекающие варианты и повтор вопроса о родстве Фарамира.
- Объяснения «Двух крепостей» содержат сведения из соответствующих эпизодов вместо простого повторения ответа.
- Правильные позиции равномерно распределены: «Две крепости» 25/25/25/25, «Возвращение короля» 17/17/17/17/16/16, «Братство кольца» 9/9/8/8/8/8. Текст правильного ответа и соответствие ключа сохранены у всех 253 карточек.

Успешный API-тест проверяет сохранность ключей и поведение приложения, а фактическую правильность подтверждает отдельная редакционная проверка.

Два онлайн-прогона проверили каждый из 253/253 новых вопросов: 14 раундов, баллы и раскрытые объяснения совпали с исходниками; ключи до завершения не раскрывались. В обоих прогонах последние проверки старой попытки выявили неверные ожидания проверочного скрипта. Сервер корректно отклонил ответ после 30-минутного срока (`409 deadline_exceeded`) и завершение попытки без принятых ответов (`400 validation_failed`). Проверки этих ограничений подтверждены отдельно. Изменений приложения из-за этого не делалось.

Старую пустую попытку нельзя использовать для проверки оценки через API. Её закрытые ключи и объяснения проверены другим способом: все три записи в резервной копии соответствуют исходным вопросам, а контролируемый набор и манифест в действующей SQLite побайтно совпали с копией до публикации. Оценка старой попытки и раскрытие её объяснений через API не заявляются проверенными. Скрипт исторической проверки использует только чтение и проверяет точный хост/PVC.

Итоговые доказательства: `ONLINE_VERIFICATION.json` содержит фактические 14 результатов, сохранённые вторым API-прогоном, и результат отдельной исторической проверки; `HISTORICAL_DB_PROOF.json` содержит контрольные суммы. Исправленный исторический блок проверен отдельно с сохранёнными завершёнными раундами, без третьего повторения 253 отправок. Полный файл `tools/smoke.py` после изменения исторического блока целиком не перезапускался.

Незавершённой работы по этому LOTR-аудиту нет. Проверки вариантов и объяснений остальных наборов продолжают учитываться отдельно в уже открытых задачах `quiz_master-2jd` и `quiz_master-dhu`; этот отчёт не означает фактологическую проверку всего каталога.
