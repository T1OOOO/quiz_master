# Мобильный интерфейс: созвездия и ответы

Источник интерфейса: `388e5c0c` (базовый выпуск 74, `82fb9c57`). Ещё не опубликован. Последняя публичная версия описана в WATER_PHOTO_20261020/PUBLISHED.md.

Нажатие на звезду или её подпись открывает сведения в нижней панели; выбор заметен на схеме и в кнопке повторного открытия. Подписи сохраняют экранный размер, учитывают масштаб текста, не перекрывают точки; рисование и попадание используют общий расчёт. Кнопки зума используют центр фактической области, двойное касание — координаты сцены без повторного преобразования. Список созвездий прокручивается при открытой клавиатуре, в том числе на маленьком экране в альбомной ориентации.

Проверенные ответы сохраняют читаемый цвет текста. Тёмная палитра использует графитовый фон, синие акценты и приглушённый фон ошибки. Фотографии сохранены. Визуальные вопросы запрашивают шесть вариантов, при меньшем наборе остаётся корректный меньший пул. После проверки положения страны показываются загруженные столица и сухопутные соседи; однообразная инструкция убрана. Отсутствующее описание остаётся пустым: исправлена найденная независимым рецензентом ошибка приведения null к String, воспроизведённая детерминированным тестом.

Мобильная проверка Chrome 361×738, DPR 3.5: нажатие на точку Бетельгейзе открыло карточку; поиск «Большая» выбрал Большую Медведицу; зум и сброс работают; проверенный ответ читается. Клавиатура, масштаб текста 1.5, размеры 320×568 и 740×360 с безопасными отступами проверяются виджетными тестами. Физический Android не подключён.

Для следующего выпуска подготовлена экономная упаковка: локальный полный пакет и полный хеш-манифест интерфейса сохраняются. На сервер передаётся точный набор всех JSON для репетиции связей статей и изменённые файлы web-delta. Полный набор файлов готового образа всё равно сверяется с полным манифестом.
