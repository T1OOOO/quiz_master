### Причины в коде (с ревью)

**High**
- **Задержка/пропуск тапа** — `onDoubleTap` и `onTapUp` на одном `GestureDetector` (3658–3671): распознаватель ждёт 300 мс двойного тапа; на практике первый тап теряется. Фикс: выбор по `onTapDown` + ручной детект второго тапа (или `RawGestureDetector` с `DoubleTapGestureRecognizer`).
- **Геометрия всех 177 стран пересчитывается на каждом кадре пана** — `_factLabels` внутри `ValueListenableBuilder` контроллера (3100–3533): `footprint` по 10 654 вершинам, `bounds()` ×4 в компараторе сортировки (3216–3220), `TextPainter.layout` на каждую метку. Фикс: кэшировать площади/bbox/центры при смене `features`, в билдере оставить только проекцию и коллизии.
- **`_MapPainter.paint` строит все `Path` дважды за кадр без кэша** (3812–3821, 3856–3864, 4022–4030); на пинче `shouldRepaint` всегда true (4149). Фикс: `Path` per feature + заливка в `ui.Picture`, перерисовывать только обводку выбранного и метки.

**Medium**
- При масштабе 1 карту можно утащить за экран: `constrained: false` + `boundaryMargin = max(w,h)` (3636–3639). Фикс: `boundaryMargin: EdgeInsets.zero` при scale == 1.
- `selected` и `highlighted` почти одного цвета (`0xff467eaf` / `0xff537b9a`, 3825/3827) — в викторине это разные смыслы. Фикс: разный тип обводки/иконка.
- Колесо над картой перехватывает скролл страницы; `MapInteraction` блокирует физику и для мыши (map_interaction.dart:69–71). Фикс: зум только с Ctrl/⌘, для `PointerDeviceKind.mouse` не блокировать скролл.
- Нет клавиатуры, hover‑курсора и тултипа (3633–3756). Фикс: `Focus` + `CallbackShortcuts`, `MouseRegion` → подпись страны.
- Микро‑страны непопадаемы: point‑in‑polygon без допуска (3674–3680), в отличие от водоёмов (3691–3697). Фикс: fallback «ближайшая страна в радиусе 12/scale px».
- Скринридер не может выбрать страну: `excludeFromSemantics: true` (3656), метки без `onTap` (3268–3273).
- `_centroid` берёт `polygons.first` (4122), а не крупнейший — номера викторины для Канады/России/Индонезии могут лечь на остров.
- Шрифты 9–10 px, `TextPainter` без `textScaler` (3963–3975, 4088, 4260).

**Low**
- Одним пальцем страницу с карты не проскроллить (map_interaction.dart:44–46) — на телефоне 300 px «мёртвой» зоны (`_LazyHistoryEventMap` 1066).
- `bounds!`, `polygons.first.first`, `ring.first` падают на пустой геометрии (3038, 4122, 3816).
- Мёртвый `flags` в painter (3734, 3795, 4142); магические пороги 2.25/1.5/40/16/8/108/112/160 в трёх местах; 45 идентичных строк вызова карты в country_learning.dart:1281–1330 и 2012–2060.

### Что хорошо
Камера переживает ресайз вокруг той же точки (2952–2976, тест country_camera_resize_test), толщина линий/меток делится на `sceneScale` (3869, 3929), коллизии меток с бюджетом флагов (3114–3118, 3159), подпись столицы крепится к реальной точке (3444–3447), кнопки зума 48×48 и перестройка при низкой карте (3557–3614), пинч/двойной тап/трекпад покрыты тестами.

### Быстрые победы (карта)
1. Убрать потерю первого тапа (3658–3671) — ~15 строк.
2. Кэш `Path` + `ui.Picture` заливки (3812–3850).
3. Вынести `footprint`/`landBounds`/центры из `ValueListenableBuilder` (3172–3246).
4. `boundaryMargin: EdgeInsets.zero` при scale 1 (3637).
5. Fallback хит‑теста для микро‑стран (3678–3680).
6. Телефон: карта на всю доступную высоту (сейчас ~160 px), зум‑кнопки не поверх суши, одна кнопка «Слои».

## 2. История (`KnowledgeAtlasPage` section 'history', lib/knowledge_atlas.dart; lib/chronology_timeline.dart)

### Как устроено сейчас
- Отдельного окна нет: это карточка **в конце** списка Квизипедии (quizipedia.dart:888) → общий `KnowledgeAtlasPage` для history/culture/people (knowledge_atlas.dart:626–630). На телефоне до неё ~12 карточек прокрутки.
- Маршрут `/history` и `HistoryPage` (journey_pages.dart:829) — это история **попыток викторин**; с историческими событиями не связан. Кнопка «История» на экране результата ведёт туда (journey_pages.dart:260, 302).
- Тело: кнопка «Тренировать связи», поиск, 6 чипов эпох, переключатель «Линия времени / Карта событий», затем лента + 105 карточек списком (636–770).
- `ChronologyTimeline` — горизонтальный `ListView.builder` с карточками `164*scale` px; шкала **порядковая**, не временная (chronology_timeline.dart:84, 196, 312). Зум меняет только ширину карточек.
- Детали события — modal bottom sheet (1211–1236) с «что/почему/что изменилось», источником и стрелками по видимому списку.

### Что увидел в браузере
- Десктоп: лента — полоска ~160 px, 8 событий в кадре, без полос эпох и засечек веков; под ней тот же список ещё раз. Тап по точке только подсвечивает колонку, деталей не открывает.
- Телефон: шапка (подсказка + кнопка + поиск + 7 чипов в 4 ряда + переключатель) занимает **весь первый экран**; лента видна только после прокрутки и показывает **2 события** на кадр → 105 событий = ~50 свайпов.
- Карта событий: после загрузки **ни одного маркера** — просто карта мира с подписями крупных стран; где лежат 73 привязанных события, не видно. Выбор страны фильтрует список, но подсветка едва заметна.
- Чип даты в списке переносится и режется («около 9600 до н. э.–8200 до»).

### Причины в коде (с ревью)

**High**
- **Дистракторы в вопросах о дате всегда одни и те же** (knowledge_atlas.dart:360–375): `candidates.take(5)` берёт 5 самых ранних дат → для «Высадка на Луну 1969» варианты «около 10000 до н. э.» и т. п. Фикс: 5 ближайших по `|year − event.year|`.
- **Лента не показывает время** (chronology_timeline.dart:84, 196, 312): зазор 10000→3100 до н. э. такой же, как 1914→1917; нет полос эпох. Фикс минимум: заголовок‑полоса эпохи над первым событием эпохи + век серым; полный — режим с масштабом по годам (лог для до н. э.).
- **Все `questions` пересчитываются на каждый `setState`** (338, 984, 1002), включая O(n²) `events.where(...).length` (348–353) — на каждую букву в поиске. Фикс: посчитать один раз в `_load()`.

**Medium**
- 105 карточек строятся eagerly (`ListView(children:)`, 668–746, 750–770); лента заново меряет 105 заголовков `TextPainter` (CT:197–218). Фикс: `ListView.builder`, кэш высот.
- `_practicePairs` создаёт ~5 400 пар в каждом build (CT:139–151, 188); первые 104 вопроса — про одно и то же первое событие.
- Выбор не прокручивает ленту (CT:104, 319; KA:1229): «следующее событие» в sheet двигает выбор, лента стоит, sheet её закрывает. По умолчанию выбрано первое событие (654–656) — ложная точка.
- Нет связи событие ↔ карта (710–718, 1031–1102): карта и лента взаимоисключающие, страны события в карточке не показаны, хотя `countryIds` есть (65).
- Нет пути «вопрос → лента» и счётчика прогресса (1307, 1351–1379): `_questionIndex % n` крутится бесконечно.
- Конфликт названий «История» (main.dart:209; journey_pages.dart:829; app_ru.arb:47 vs quizipedia.dart:918).

**Low**
- Две таксономии эпох: лента делит по году на 7 (CT:112–137), атлас по полю `era` на 6 (KA:1535–1542).
- Заголовки режутся на 164 px / 3 строки (CT:196, 371–372).
- Подсказка поиска «имён, произведений, периодов» на экране событий; поиск не ищет по `what/why` (647–652, 969–972).
- Десктоп: одна колонка на любой ширине (668), sheet на всю ширину (1219–1221).
- `_quizValue` патчит английские даты строковой заменой `BCE` (1567–1570).

### Что хорошо
Карта грузится лениво (quizipedia.dart:1008–1089, тест фиксирует `mapBuilds == 0`); формат «что/почему/что дальше» + обязательный https‑источник; русские даты «до н. э.», «около», диапазоны корректны (493–497); ось не ломается при масштабе текста 1.6; вопросы «какое последнее?» из 6 соседних событий (384–393) реально учат порядку; тренировка сужается до фильтра эпохи (979–994).

### Предложение: отдельное окно истории
Новый `lib/history_atlas.dart` (~350 строк, из них ~280 — перенос `_history`, `_historyEventRows`, `_historyMapView`, `_eventCard`, `_showEvent` из knowledge_atlas.dart). `KnowledgeAtlasPage` остаётся для culture/people, для `section == 'history'` делегирует.

Панели (Column; на ≥ 840 px — Row через `LayoutBuilder`):
1. **Навигатор**: чипы эпох с количеством («Средние века · 21»), поле «Год» (бинарный поиск ближайшего события), поиск. На телефоне — одна строка горизонтальных чипов, не 4 ряда.
2. **Лента**: тот же `ChronologyTimeline` + полосы эпох над первым событием эпохи, автопрокрутка к `selectedId` (`didUpdateWidget` + `animateTo`), стрелки ←/→ через `Focus`. На телефоне — на всю ширину, минимум 3 события в кадре.
3. **Карточка события** — инлайн под лентой (телефон) / справа (десктоп), не sheet: существующая `_eventCard` + чипы стран + «на карте» + «тренировать это событие».
4. **Карта** — сворачиваемая, не взаимоисключающая: **маркеры/счётчики событий по странам**, подсветка `event.countryIds` при открытой карточке, выбор страны фильтрует ленту (переиспользуется `_LazyHistoryEventMap`; оставить `Key('history-view-toggle')`, чтобы history_event_map_test остался зелёным).
5. **Тренировка** — существующий sheet + `i/n` + «Показать на ленте».

Вход: карточку истории поднять в начало списка Квизипедии (quizipedia.dart:888) с подзаголовком «105 событий · 10 000 до н. э. — 2003»; маршрут `/quizipedia/history`, чтобы была ссылка. Оценка: 1–2 дня, ~400 строк diff; правится только `knowledge_atlas_test.dart:68–179` (sheet → инлайн).

### Быстрые победы (история)
1. Ближайшие дистракторы дат (360–375) — 6 строк.
2. Кэш `questions` (338) — 2 строки.
3. Автопрокрутка ленты к выбранному + `selected = null` по умолчанию — ~12 строк.
4. Полосы эпох на ленте (CT:317–382) — ~20 строк.
5. Переименовать `/history` → «Мои результаты» и поднять карточку истории наверх — 3 строки.
6. Телефон: чипы эпох в одну прокручиваемую строку, подсказку‑абзац убрать.

### Сеть и безопасность
- Base URL через `QM_API_BASE_URL` (journey.dart:5–9), принимаются только https или loopback (api_repository.dart:341–365). Секретов в коде нет. Токен гостя только в памяти.
- `expiresAt` сессии нигде не проверяется → после протухания 401 без ребутстрапа.
- Таймауты 10 с, `sendTimeout` нет; retry/interceptor — 0, хотя `retryable: true` выставляется.
- Два стиля обработки ошибок в одном клиенте (`validateStatus: (_) => true` vs без него); любая `DioException` → `'network'`.
- Плюсы: канонический JSON + sha256 digest, closed‑set валидация ответов (×18), кросс‑чек `participantId/revision`.

- `pubspec.yaml:2` — шаблонное описание, `intl: any`.
