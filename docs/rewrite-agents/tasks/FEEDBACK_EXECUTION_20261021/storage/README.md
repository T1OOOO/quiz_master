# Архивирование перед выпуском

Пользователь явно разрешил архивировать девять старых сборок из
`../release/archive-proposal.json`, проверить архивы и удалить только их
распакованные оригиналы. Постоянные копии сохраняются в
`E:/Backups/quiz-master/server-20261021/`, вне репозитория и `.run`.

`archive_orchestrator.py` фиксирует точные девять путей, проверяет исходный
манифест до и после копирования и повторяет проверку использования перед
удалением. Манифест содержит содержимое файлов, пути, типы, владельцев, права,
наносекундное время, xattrs и цели симлинков. Linux-проверка восстанавливает
каждую запись оригинального архива в ограниченное временное дерево и сравнивает
результат с исходным манифестом. Порции ограничены32МБ/256записями; отдельный
файл —512МБ, с дополнительной проверкой доступной памяти.

Удаление требует полной квитанции Linux-восстановления и отдельного
независимого обзора, связанных с точными SHA256 архива, исходного манифеста и
квитанции. Архивы не удаляются. Код прошёл независимые проверки, приведённые
рядом; это не заменяет фактическое восстановление каждой сборки.

Очистка кэшей выделена в `cache_cleanup.py`. Историческое предложение36папок
содержало12папок внутри архивируемых сборок, поэтому их2 547 445 760байт нельзя
считать повторно. Исправленный отдельный пакет содержит24папки на
2 187 223 040байт и фиксируется полным хэшем `cache-cleanup-manifest-v5.json`. Перед удалением проверяются
проектные процессы, открытые файлы, контейнеры, Kubernetes и монтирования, затем
идентичность каждой папки непосредственно перед удалением.

Разрешённая очистка Docker касается только неиспользуемого кэша сборщика старше
часа. Наборы опубликованных образов Docker и CRI сверяются до и после.
Контейнеры, образы, тома, резервные копии, PVC, медиа и резерв ext4 сохраняются.
Порог20%проверяется после очистки и повторно перед выпуском; прогноз не
заменяет фактический результат.

Для ускорения проверки подготовлена изолированная WSL2-среда `QuizArchiveVerify21`
внутри постоянного хранилища. Официальный Alpine rootfs проверен по SHA512;
установлены подписанные GNUtar, Python и настоящий findmnt. `local_wsl_restore.py`
меняет только транспорт неизменного закреплённого проверителя и фиксирует
Linux-ядро, дистрибутив и хэш базового кода в каждой порции доказательств.
Независимый обзор принят; реальный fixture повторно проверен исполнителем.
Первые две сборки проверены на серверном Linux, последующие — в локальном WSL2.
Серверный временный процесс проверки прерван по точному хэшу кода и идентичности
собственного процесса; временные деревья убраны, исходники сохранены.

Актуальный пакет v6 исключает ещё три папки, уже отсутствующие после внешней
очистки: осталось21папка на1 780 559 872байта по исходному измерению.
Фактическое удаление21папки и очистка кэша сборщика завершились; наборы образов
сохранены. Подробности — в `execution-progress-20261021.md`.

Последний локальный прогон:30тестов прошли. Новый снимок после удаления
сгенерированных записей создаёт `repack_subset_archive.py`; исходный архив
сохраняется, новая Linux-проверка и независимый обзор обязательны.
