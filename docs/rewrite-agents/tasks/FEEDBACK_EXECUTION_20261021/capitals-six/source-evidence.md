# Черновик: ещё два варианта для `prep-capitals-1`

Проверено 21 октября 2026 года. Это частный черновик для независимой факт-проверки; он ничего не импортирует и не меняет в каноническом квизе. Во всех строках ниже ответ из текущего ключа сохранён. Новые варианты — реальные города той же страны, не являющиеся правильным ответом на точную формулировку вопроса.

## Уточнённое доказательство для 015

Проверка раскрыла прямые официальные подтверждения: [публикация президента Боливии](https://presidencia.gob.bo/index.php/nota_prensa/nueva-etapa-en-las-relaciones-presidente-de-chile-llega-a-bolivia-y-es-recibido-con-honores-en-plaza-murillo/) называет Casa Grande del Pueblo в Ла-Пасе местом национального правительства, а [Палата депутатов](https://diputados.gob.bo/noticias/diputados-visitan-el-nuevo-hemiciclo-del-moderno-edificio-legislativo/) указывает законодательный гемицикл в Ла-Пасе. Поэтому ответ Ла-Пас сохранён, а stem сделан точнее. Нужна лишь короткая повторная проверка трёх новых формулировок.
