### Concrete Findings

#### P1-1: `validate_asset_delta` includes `EXPECTED_GENERATED_WEB_MUTATIONS` under `assets/` in `changed_assets`, causing any real Flutter web build to fail against the 168-entry `asset-delta-allowlist.json`
- **Location:** [`release_executor.py` (`EXPECTED_GENERATED_WEB_MUTATIONS`, `validate_asset_delta`)](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L46-L46), [`release_executor.py`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L202-L210), [`prepare_package.py`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/prepare_package.py#L73-L74)
- **Trigger:** Running [`prepare_package.py`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/prepare_package.py#L73-L74) or [`collect_inputs()`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L270) on a candidate web build where Flutter regenerates `assets/AssetManifest.json`, `assets/AssetManifest.bin`, `assets/AssetManifest.bin.json`, `assets/NOTICES`, or `assets/FontManifest.json`, while [`asset-delta-allowlist.json`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/asset-delta-allowlist.json#L1-L842) lists only the 168 content/font assets.
- **Consequence:**
  1. [`EXPECTED_GENERATED_WEB_MUTATIONS`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L46) explicitly lists five generated paths under `assets/`: `"assets/AssetManifest.json"`, `"assets/AssetManifest.bin"`, `"assets/AssetManifest.bin.json"`, `"assets/FontManifest.json"`, and `"assets/NOTICES"`.
  2. However, line 205 of [`validate_asset_delta()`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L205-L207) computes:
     ```python
     changed_assets = {name for name in changed if name.startswith("assets/")}
     if changed_assets != set(allowlist): raise GuardError("approved asset allowlist must equal every added or modified asset")
     if changed - changed_assets - EXPECTED_GENERATED_WEB_MUTATIONS: raise GuardError("web release changed an unapproved non-generated path")
     ```
  3. Because all five generated manifest paths start with `"assets/"`, they are placed into `changed_assets` before `EXPECTED_GENERATED_WEB_MUTATIONS` is ever subtracted. Line 206 (`changed_assets != set(allowlist)`) immediately raises `GuardError("approved asset allowlist must equal every added or modified asset")`, and the five `"assets/..."` entries in `EXPECTED_GENERATED_WEB_MUTATIONS` on line 207 are unreachable dead entries (`changed - changed_assets` has already stripped every `"assets/..."` path).
  4. [`test_release_executor.py`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/test_release_executor.py#L20-L37) missed this because its synthetic candidate dicts only mutated `'main.dart.js'` and never included `'assets/AssetManifest.json'` or `'assets/AssetManifest.bin.json'`.
- **Smallest Adequate Correction:**
  1. In [`release_executor.py` (`validate_asset_delta`)](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L205), exclude `EXPECTED_GENERATED_WEB_MUTATIONS` when computing `changed_assets`:
     ```python
     changed_assets = {name for name in changed - EXPECTED_GENERATED_WEB_MUTATIONS if name.startswith("assets/")}
     ```
     (And in [`load_asset_allowlist()`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/release_executor.py#L195-L199), optionally reject `name in EXPECTED_GENERATED_WEB_MUTATIONS` so generated manifests and content/font asset allowlist entries stay strictly disjoint.)
  2. In [`test_release_executor.py`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/FEEDBACK_EXECUTION_20261021/release/test_release_executor.py#L23-L24), include a mutated generated manifest under `assets/` (e.g., `'assets/AssetManifest.bin.json': 'new-manifest'`) alongside `'main.dart.js'` in `test_exact_approved_asset_bytes`.
