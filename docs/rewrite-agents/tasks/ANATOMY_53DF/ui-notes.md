# Anatomy atlas UI notes

The diagram is a code-native anterior schematic. It labels the viewing convention
explicitly: patient right appears on the viewer's left. It is not a diagnostic
image or a source of exact locations. Large structures have distinct silhouettes;
small and distributed glands remain reachable in the 44px accessible list.

The camera is controlled only through pan, pinch and explicit zoom/fit controls.
Selecting from the diagram or list never auto-zooms or repositions it. Region,
system and gland-type filtering affect both the schematic layers and the list.
