# Quizipedia v1 implementation contract

2026-10-05. User authorizes interactive learning games alongside ongoing difficulty/tags. Root chooses the advisor's Flutter painter/InteractiveViewer recommendation: no dependency or engine migration for static geometry. This is local unranked learning practice, like Study. It never calls attempt APIs or stores competitive scores.

Root owns `assets/quizipedia/**`, data acquisition/manifest/validation, `pubspec.yaml`, main route/import, SourceScaffold navigation and localization integration. Flutter implementer exclusively owns new standalone `lib/quizipedia.dart` and `test/quizipedia_test.dart`. Import normal Flutter material/services and dart:convert/math; it is a library, not a part of main.dart. Export `QuizipediaPage` with its own scaffold. Keep all new text in one RU/EN text map/helper inside this new library (locale determined by Localizations.localeOf), so no competing ARB/codegen owner. Parent app localization owns language/theme changes. Root adds `/quizipedia` route and existing drawer entry.

Data is `assets/quizipedia/catalog.json`, `schema_version: qm-quizipedia/v1`. Common target fields `id`, `name_ru`, `name_en`, `difficulty_level` (1..10), `tag_ids`, `explanation_ru`, `explanation_en`, `source_url`. Local answer IDs may reside here because this explicitly unranked surface is separate from the API DTOs/private ranked bundles. Never print a hidden answer in image semantics/tooltips before submission.

* `credits`: list `{id, attribution, source_url, license, license_url}`. Reachable credits dialog with source/license links (url_launcher existing dependency). Detailed filename hashes/acquisition dates live in bundled `manifest.json` and repo manifest; no answer names in active challenge credit UI until answer unless the user explicitly opens credits. Credit dialog disclosure is deliberate.
* `countries`: all available map features `{id, name_ru, name_en, polygons}` plus common target fields for selected countries. Coordinates are normalized equirectangular world `(x=(lon+180)/360,y=(90-lat)/180)`. Each country's `polygons` is a list of polygons; each polygon is a list of closed rings; each ring is a list of `[x,y]` pairs. Preserve holes. A feature with no target is background only. `map_target_ids`: exact reviewed subset of available country IDs. `flag` on targets is Unicode regional-indicator flag; the app can show the two-letter ISO as a fallback but never display the country name for a flag challenge.
* `anatomy`: `{image_asset,width,height,credit_id,targets}`. Targets common fields plus `hotspots: [{x,y,radius}]` in normalized original image space. Multiple spots may share one answer target. Render image and spots in exactly the same aspect ratio. Background diagram has no embedded names. All candidate spots are numbered neutrally. Identify highlight -> four target-name options; name -> tap target/numbered accessible button. If nearby spots overlap, show choices rather than arbitrarily picking nearest; exact image-aligned coordinates stay factual.
* `landmarks`: list common fields plus `{image_asset, credit_id, country_iso2, city_ru, city_en}`. Show real bundled photo and four similarly styled landmark names, or four cities for a location challenge. Image alt text is neutral `Photograph` before answer. Error state has retry and permits exiting; do not silently quiz on an unloaded photo.
* `constellations`: list common fields plus `stars: [{id,name,ra_hours,dec_degrees,magnitude}]`, `lines: [[star_id,star_id]]`, `credit_id`. Fixed J2000 educational atlas, explicitly not current sky; constellation stick figures are editorial patterns, not official IAU boundaries. Each pattern renders stars from documented RA/Dec equirectangular projection, unwrap RA at 0/24 when necessary, astronomical RA increases to the left. Fit each pattern maintaining common coordinate scale in x/y; drawing changes on tap/explore can reveal star names AFTER answer or in Explore only. Never independently stretch axes into an arbitrary shape. Identify the shown pattern among four constellation names. Allow pan/zoom and explore tapping stars to inspect name/magnitude. No unverified real-time horizon/location claim.

UI: library with four real game tiles (map includes both flag/tap and highlighted-country/name directions; anatomy both directions); mode choice Explore/Challenge; ten-question short randomized sessions (or all targets when fewer than ten), no repeats in a round, randomized four options including exactly one correct target, correct/wrong feedback, explanation, reveal correct target, Next, Retry error, Restart and Exit. Keep current submitted answer until Next, block double scoring, show progress and final score. For map/body selection, explicitly press Check after a tentative tap so pan/zoom gestures never submit. In challenge hide names/labels before answer. Do not show an unrelated distractor's explanation.

Geometry: true ring/path containment, bounds only for pruning; distinguish holes and multipart features. Tap coordinates originate in scene space (InteractiveViewer child-local pointer or controller inverse transform, never both). Pan/zoom, reset, and accessible options/numbered targets each have at least44 logical pixels. Background countries cannot be scored as the correct target unless bound in map_target_ids. Ocean tap has explicit neutral no-selection state. Screen readers/keyboard can use alternative controls, feedback announces live region. Long prompt/options and text scaling scroll at390px, no fixed viewport overflow.

Tests first: real polygon/holes/multipart containment fixtures and transform behavior, strict asset loader target/line references and difficulty boundaries, no-repeat/one correct option, wrong/correct/double-answer/restart, both map/body directions, missing asset error, no API calls, challenge names hidden, Explore labels,390px text-scale usable scrolling. No tests/build until actual granted host resource lease. Report NOT_RUN accurately and give root focused commands to execute at integration.

Worker is not alone: preserve current difficulty patch and foreign changes; no edits to main/pubspec/assets/ARB, no new children, no git index/commit/push, no deploy. Beads quiz_master-1x6.2; hub quizipedia-flutter-20261005. Source assets and factual coordinate/content review are independent gates before publication.
