# Мобильная сетка вопросов и загрузка флагов

Источник окончательной сборки:9de2ad043695e45c2111298d9006e4b2376b2472. Сетка открывается корневым навигатором поверх кнопки отзыва. Флаги загружаются одним JSON-пакетом250 исходных PNG, побайтно неизменных; есть изоляция сбоев, освобождение изображений и повторная загрузка. Фотографии и обложки версии71 сохраняются.

290 Flutter-тестов прошли, анализатор без замечаний; после изменения только тестового ожидания диапазона4–6 вариантов отдельно прошли9 проверок атласа. Проверены один запрос пакета, отсутствие запросов отдельных флагов, повтор после отказа и реальное попадание по номеру19. Независимые проверки исходников приняты; публикация требует отдельной приёмки точного образа.

Полное дерево web готового образа должно совпасть с чистым билдом. Сохраняются проверки APIe2884077,165 файлов квизов,105 банков/4520 вопросов, восстановления базы,20% свободного imageFS, точной квитанции образа и отката на71.
