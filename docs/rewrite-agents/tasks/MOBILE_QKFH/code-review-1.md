### Blocker 2 — Unanswerable / underspecified question stems where child qualifier is only in `fieldPath`, not in `fieldRu`/`fieldEn` or `nameRu`/`nameEn`
[`FactPracticePage`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice.dart#L362-L364) renders every question stem solely from `f.fieldRu`/`f.fieldEn` and `f.nameRu`/`f.nameEn` (`'Что указано в разделе «${f.fieldRu}» для «${f.nameRu}»?'`), and the browse list ([`fact_practice.dart`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice.dart#L302-L303)) renders only `f.nameRu` and `${f.fieldRu} · ${f.valueRu}`. In multiple extractors, the sub-item key is placed only in `fieldPath`, producing ambiguous/unanswerable prompts:
1. **Religious-group shares (`countries`)**: [`_countryFacts`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L270-L286) sets `fieldPath: 'religion_shares.${entry.key}'`, `fieldRu: 'Доля религиозной группы'`, `fieldEn: 'Religious-group share'`, without naming `entry.key` (`Christians`, `Muslims`, `Unaffiliated`, `Hindus`, `Buddhists`, `Folk Religions`, `Jews`, `Other Religions`). The user is asked *"Что указано в разделе «Доля религиозной группы» для «Афганистан»?"* without specifying **which religion's share** is requested.
2. **Constellation star metrics (`sky`)**: [`_skyFacts`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L419-L450) sets `nameRu`/`nameEn` to the **constellation** name and `fieldRu`/`fieldEn` to `'Звёздная величина'` (`'Magnitude'`), `'Прямое восхождение'` (`'Right ascension'`), or `'Склонение'` (`'Declination'`), putting `$starId` only in `fieldPath: 'stars.$starId.magnitude'`. For a multi-star constellation (e.g. Andromeda has 6 stars in [`catalog.json`](file:///E:/Projects/quiz_master/next/apps/quiz_app/assets/quizipedia/catalog.json#L288-L356)), the prompt asks *"Что указано в разделе «Звёздная величина» для «Андромеда»?"* without naming which star (`Альферац`, `Мирах`, `Аламак`, etc.) is being asked about.
3. **Food ingredient amounts & variant fields (`food`)**: [`_foodFacts`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L794-L808) emits `fieldPath: 'ingredients.$i.amount'`, `fieldRu: 'Количество'` (`'Amount'`) with `nameRu` = dish name, never naming the ingredient. Similarly, [`variants.$i.region`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L839-L854) and `variants.$i.difference` ask for `'Регион варианта'` / `'Отличие варианта'` of the dish without naming which variant.
4. **Brand former-name years/notes and logo history (`brands`)**: [`_brandFacts`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L938-L996) emits `former_names.$i.from_year` (`'Год начала'`), `to_year` (`'Год окончания'`), `note` (`'Примечание к названию'`), and `logo_history.$i.year` / `text` under the brand's `nameRu` without identifying which former name or logo entry is referenced when a brand has multiple entries.
5. **Belief edge labels & scopes (`belief`)**: [`_beliefFacts`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L732-L757) emits `edge.label` (`'Связь'`) and `edge.scope` (`'Контекст связи'`) with `nameRu: '${from['name_ru']} → ${to['name_ru']}'`, so `edge.scope` asks for the citation context without stating the relationship label, and shares a distractor family with `edge.label`.
6. **Work cast roles (`works`)**: In [`knowledge_atlas.json`](file:///E:/Projects/quiz_master/next/apps/quiz_app/assets/quizipedia/knowledge_atlas.json#L254-L280), `cast` tuples are `[person_id, role_ru, role_en]` (e.g. `["bogart", "Рик Блейн", "Rick Blaine"]`, `["bergman", "Ильза Лунд", "Ilsa Lund"]`).     - **Incompatible subfields share the same `_family` prefix**:

(Moreover, `president.checked` is verification metadata, violating [`coverage.md`](file:///E:/Projects/quiz_master/docs/rewrite-agents/tasks/MOBILE_QKFH/coverage.md#L3) *"Internal IDs, asset filenames, coordinates, and source URLs are metadata, not subject-matter questions"*.)
      - `links`, `culture`, `waters`: `.name` and `.relation` ([`fact_practice_models.dart`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L334-L359)) share `_family`, mixing entity names (e.g. `"Дудук"`, `"Атлантический океан"`) with relation prose (`"Омывает берега"`, `"Природный ресурс страны"`).
