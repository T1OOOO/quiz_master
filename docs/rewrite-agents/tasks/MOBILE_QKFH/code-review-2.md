Because `leaf == 'relation'` is not in the `'prose'` set in [`_valueKind`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/fact_practice_models.dart#L1428-L1448), `_valueKind` returns `'label'`, pulling random country capitals, languages, currencies, or regions as distractors for `'Связь: Природный ресурс'` and `'Связь с водоёмом'`.
