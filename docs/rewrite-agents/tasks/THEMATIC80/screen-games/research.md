## Ограничения

* Официальная страница DreamWorks для `Shrek` в текстовом представлении почти не раскрывает сюжет, поэтому деталь о квесте дополнительно зафиксирована с открытой официальной страницы фильма в `sources.json`.
* Для `Sherlock` доступная первичная страница — опубликованный BBC Writersroom сценарий; вопросы избегают деталей, не подтверждённых им.
* В пилотах один вопрос об актёре; остальные опираются на правила миров, предметы, роли и события.
