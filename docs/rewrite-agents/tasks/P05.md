ARCHITECTURE DECISIONS:

- Reuse the root `quiz_master` Go module and Go 1.25 declaration. Use standard `net/http` routing and `pgx/v5`; no ORM, DI framework, alternate router, service split or speculative repository interfaces.
- Environment-only config with explicit validation; no implicit `.env` loading. Server startup must propagate cancellation and close the pool cleanly.
- SQL migrations are ordered, checksummed and applied transactionally under an advisory lock. No destructive automatic down migration.
- Identity is a stable opaque ID with explicit `guest` or `account` kind; display name is never authorization. P05 may create guests and authenticated sessions but must not implement passwords or guest merge (P13).
- Session credentials are random 256-bit opaque tokens returned once; store only SHA-256 token digest, participant ID, created/expiry/revocation timestamps. Authorization resolves a principal from the token digest and rejects expired/revoked/unknown tokens without leaking lookup details.
- Transaction helper accepts context, never begins nested transactions implicitly, rolls back on callback error/panic path, commits once, and wraps errors so `errors.Is/As` remains useful. Later answer/room operations choose stronger isolation explicitly.
