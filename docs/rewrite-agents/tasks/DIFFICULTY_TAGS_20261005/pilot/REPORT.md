# Advisory annotation pilot

This is a private, bounded recommendation under CONTRACT v1, not a bulk annotation or publication.  It contains 42 records: 36 quiz records (food 8, country flags/capitals 7, nature 5, history 4, LOTR 4, Terminator 2, Harry Potter 2, Game of Thrones 2, cartoons 2) and one accepted Study question from each of the six modules.

Every selected question was read with its full option set, keyed answer and explanation.  Each record has a 1–10 editorial estimate, sorted existing tag IDs, an individual Russian rationale, confidence and flags.  Context is a subset of editorial tags and contains only `player_safe` broad domain/topic/franchise/medium IDs; country, ingredient and answer-specific entities are private editorial tags.

Vocabulary gaps were not filled with invented IDs.  The three flagged questions identify review needs: the global cheese-theft and ancient-popcorn claims need source audit; the absolute claim that adult cat meowing is exclusively for people needs wording/source audit; the Noodle internet-meme question is off-topic for a dog-biology pack.  No score is raised merely because of those concerns.

Remaining limitation: ratings are editorial priors for Russian adult general quiz players, not observed response statistics or an independent review.  The 42-record sample supports calibration and review before any bulk attachment.
