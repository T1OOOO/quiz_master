# Root: general phobias, 54-question draft

Root read all 54 complete stems, every alternative, key and explanation in
three explicit batches of 18. A literal table stores individual score,
confidence, flags and rationale; no old-difficulty/length/name classifier was
used. Exact ID coverage and frozen source byte hash were asserted. The file
uses the current 403-tag dictionary. No raw question changed.

Scores account for the near-literal aviation/phobophobia answers, transparent
neo-/techno- clues, English/Greek associations, unusual vocabulary, competing
medical definitions, and parenthetical or long keyed choices. Duplicate and
wrong-key suspicions remain concerns rather than artificial Nightmare scores.
Medical topical tags for keyed blindness/angina/dental facts are private;
the general pack and visible opaque names do not justify revealing those
answer-derived subjects in public context.

Outstanding concerns include the keyed claim that all loneliness terms
(including sociophobia) are synonyms, overlapping arithmo-/numero- and
rope/mirror/filth alternatives, nonstandard “scientific” phobia names,
unreferenced prevalence and diagnostic criteria, and a celebrity biography.
Nine phobia-name keys have generic explanations; most other explanations
incorrectly describe an object, person, duration or activity as a phobia term.
The humorous palindrome item has a mismatched clinical explanation.

This is a classification draft, not independent factual certification or
permission to rewrite answers. Independent semantic review is pending.
