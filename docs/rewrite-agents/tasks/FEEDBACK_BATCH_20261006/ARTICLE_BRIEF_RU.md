# Учебные статьи: первый редакционный пакет

Статус: исследование и черновик; не опубликовано, нужен независимый фактчек.
Владелец последующего импорта: отдельный контент-агент quiz_master-foq.

## Как связывать статью с вопросом

Для каждого материала хранить source_quiz_ids и явный список question_ids,
подтверждённые тезисы с URL источника, короткое объяснение простыми словами,
один пример и 3–5 проверочных вопросов. Ссылка «Подробнее» появляется после
принятого ответа рядом с объяснением; статья не должна выдавать правильный
ответ до отправки. Для теоретических разделов в библиотеке ограничения нет.
Мобильное представление: короткие абзацы и карточки, таблицы — лишь когда
они нужны для сравнения и доступны также вертикально.

## Первый пример: «Кийждо — каждый»

Связь: quiz vocabulary-church-slavonic, question q-vocabulary-200-94.

Черновик:

**Кийждо** — церковнославянское слово со значением «каждый», «всякий».
Если вы встречаете его в старом тексте, попробуйте заменить его современным
словом «каждый»: смысл предложения становится понятнее. Это слово говорит
о любом отдельном человеке или предмете из группы, а не об одном заранее
выбранном человеке. Короткая учебная фраза «кийждо из нас» означает
«каждый из нас». Пример составлен для объяснения, это не историческая цитата.

Чтобы запомнить слово, произнесите пару «кийждо — каждый», а затем
попробуйте самостоятельно перевести «кийждо из нас». В вопросе квиза
проверяется именно значение слова: необычное звучание не должно мешать
узнать знакомую мысль.

## Созвездия: последовательность расширения

Первый пакет — хорошо узнаваемые фигуры, затем сезонные группы северного и
южного неба. Для каждой фигуры: русское/латинское название, опорные звёзды,
проверяемые координаты и понятное отличие рисунка от границ созвездия.
Источник определения и полного списка: IAU
https://www.iau.org/IAU/IAU/Astronomy-FAQs/Constellations.aspx
Текущий J2000-атлас не является небом в реальном времени: не добавлять
локальный горизонт/время, пока не реализован и проверен соответствующий расчёт.

## Анатомия: последовательность расширения

Раздельные модули: скелет → основные органы → эндокринная система → части
головного мозга. Латинские названия сверять с FIPAT TA2:
https://fipat.library.dal.ca/TA2/
Для рисунка хранить проекцию и масштаб, разрешённую лицензию и локальные
координаты зон. Мелкие структуры выбирать также из списка с фокусом на зоне.
Терминологический источник не является лицензией на сторонние изображения.
Материал обучающий; не добавлять диагностику заболеваний или рекомендации
лечения. Полноту каждого модуля считать по проверенному списку структур.
