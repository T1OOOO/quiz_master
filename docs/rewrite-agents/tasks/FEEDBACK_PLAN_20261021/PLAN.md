## Зависимости и приёмка

1. Сначала географический renderer + контракт слоёв; параллельно независимые музыка/анатомия. Затем country UI и проверенные country facts. Общий quizipedia.dart не редактируют два агента.
2. После освобождения общих файлов — каталог/тренировки; независимо — линии времени. Контент/медиа сначала фиксируют источники, права, конечный объём первой партии и таксономию. Новые факты проверяет другой агент до импорта. Не обещать все виды животных или все структуры тела без проверяемого перечня.
3. Для каждого экрана проверить361×738 и393×851: читаемые русские подписи, доступные кнопки, отсутствие горизонтального обрезания, поиск/фильтры и возврат. Физический Android остаётся отдельной неподтверждённой проверкой.
4. Камера карты не меняется при клике по стране, выборе из списка, переключении слоя или открытии/закрытии карточки. Только отдельная явная команда «Найти на карте/Вписать» может менять камеру. Названия стран + столицы + флаги должны работать вместе.
5. Факт и объяснение появляются без лишнего клика; после ответа видны результат, верный ответ, осмысленное пояснение и ручная кнопка «Далее». Для каждого тренировочного пула —6 разных допустимых вариантов с исключением альтернативно верных ответов; существующие специальные4-вариантные банки требуют отдельного конечного расширения, а не фиктивных дублей.
6. Ленивая загрузка обязательна: главная не запрашивает все JSON/фото/шрифты; каталог грузит превью видимых строк; оригинал — при открытии карточки. Не использовать большой объединённый base64-манифест. Снять network trace холодного старта/открытия/фильтра и размеры; существующий базис —4 превью/12210B на главной. При загрузке/ошибке остаётся рабочий понятный интерфейс, а не пустота.
7. Только после целевых тестов, анализа, независимого review и реальной проверки опубликованного экрана закрывать конкретный отзыв. Скриншот/привязка/проверенный результат обязательны; субъективные отзывы не закрываются автоматически за соседнее исправление.
8. Перед будущим выпуском заново проверить серверное место: последнее состояние18.8% свободного при обязательных20%; `quiz_master-xwe4` открыт. Сохранять все опубликованные образы, полные резервные копии, PVC и5% резерв ext4. Этот план не меняет конфигурацию диска и не является новым выпуском.
