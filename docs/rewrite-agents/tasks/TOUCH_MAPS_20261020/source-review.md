1. **Gesture Lifecycle, Multi-Contact, Release/Cancel, and Parent-Scroll Restoration ([map_interaction.dart](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L1-L74))**
   - [`MapScrollView`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L4-L17) tracks active map pointer IDs in `_pointers` (`Set<int>`) inside [`_MapScrollViewState`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L19-L51) and declaratively switches its [`SingleChildScrollView`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L41-L48) `physics` between `null` (when `_pointers.isEmpty`) and `const NeverScrollableScrollPhysics()` (while any map contact is active).
   - Imperative `ScrollableState.setCanDrag` calls have been completely removed, avoiding framework layout-only assertions.
   - [`MapInteraction`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L62-L74) is stateless, looks up [`_MapScrollScope`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L53-L60) via `getInheritedWidgetOfExactType<_MapScrollScope>()`, and only registers pointer-down events (`onPointerDown`).
   - Because `onPointerUp` and `onPointerCancel` are handled on the ancestor `Listener` in [`_MapScrollViewState.build`](file:///E:/Projects/quiz_master/next/apps/quiz_app/lib/map_interaction.dart#L38-L49), any pointer whose `PointerDownEvent` hit-tested through `MapInteraction` also includes `MapScrollView`'s `RenderPointerListener` in its `HitTestResult` path. Consequently:
     - Multi-finger gestures (e.g., two-finger pinch where one finger lifts early and the remaining finger cancels or lifts later) keep the parent scroll locked until the **last** active pointer ID is removed.
     - If a `MapInteraction` subtree is unmounted or replaced mid-gesture, the ancestor `Listener` in `MapScrollView` still receives the pointer's `PointerUpEvent` / `PointerCancelEvent` and restores parent scrolling.
     - When `MapInteraction` is rendered without an enclosing `MapScrollView` (such as full-height country maps), `scope?.onStart` is a safe no-op.
