# Покрытие и проверка черновика

Статус: 40 карточек для независимого решения и факт-проверки; это не публикация и не редакционная приёмка.

## Баланс

- 20 советских/российских записей (1–20), 20 международных (21–40).
- Позиции ключа: a=10, b=10, c=10, d=10; порядок перемешан, повторяющегося цикла нет.
- Ни один режиссёр не встречается более четырёх раз; совместно поставленные фильмы исключены.
- Все 40 источников открыты 2026-10-03: прямые карточки Мосфильма для 1–20; прямые карточки AFI, Criterion и правообладателей/дистрибьюторов для 21–40. Режиссёрский кредит и использованный факт сверены по содержимому страницы; для 32, 37 и 40 зафиксирован доступ через web-рендеринг, поскольку bare HTTP был заблокирован/вернул 404.

## Риски до приёмки

- Нужны независимый blind solve и отдельная факт-проверка всех 40 дополнительных поясняющих фактов/дистракторов.
- Нужны независимый blind solve и факт-проверка всех 40 записей; авторская сверка источника не заменяет независимый редакционный вердикт.
