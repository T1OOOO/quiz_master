## Migration hazards and golden fixtures

P04/P08 must explicitly map legacy `correct_answer` without defaulting an absent answer to zero, validate the mapped index against options, and preserve missing difficulty as unknown rather than numeric zero. The fixtures should include: a nonzero legacy answer; a zero answer; valid 4-, 5-, and 6-option choices with first and last correct indexes; missing, negative, and out-of-range answers; missing/null difficulty; duplicate quiz and question IDs; malformed JSON/non-object questions; and both absent and empty `correct_multi` cases (neither implies multi-choice content). Category metadata should also remain explicit rather than silently inferred from the English directory names, which differ from Russian category values.

P04/P08 must reject duplicate quiz IDs or use an explicit, auditable resolution policy; silently relying on later-file replacement is unsafe.
