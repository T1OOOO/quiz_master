# P11S — local SQLite rewrite API

Status: **ACCEPTED by independent review; integration commit pending.**

Explicit loopback-only `sqlite:<durable file>` startup now coexists with the
unchanged PostgreSQL path; no fallback exists and memory/unsafe SQLite paths
reject. `next/server/internal/sqlite` provides file-backed identity, attempts,
receipts, finish, reveals and history. Attempts pin bundle hash/version and
reload stored controlled bundle/manifest bytes for finish/reveals after source
loss. SQLite uses one connection with foreign keys enabled, and Submit/Finish
are transactions. Same-key/same-payload replays a receipt; different payload
conflicts; key bounds, stale revision and deadline are enforced.

Changed/new files: `next/server/internal/config/{config.go,config_test.go}`;
`next/server/internal/httpapi/{attempts.go,attempts_test.go}`;
`next/server/internal/attempts/{rules.go,reveals.go}`;
`next/server/internal/sqlite/{schema.go,schema_test.go,identity.go,identity_test.go,attempts.go}`;
`next/server/cmd/api/main.go`; this report.

Observed RED→GREEN examples: explicit SQLite config was rejected; schema was
absent; same-key replay conflicted; source-loss finish scored zero; source-loss
reveal was incomplete; and orphan answer insertion succeeded before connection
FK enablement. Focused successors passed. The HTTP test drives guest, catalog,
start, answer, finish, reveal, reopen and history through actual routes and
scans catalog JSON for six private markers. Barrier tests check concurrent
finish identity and serialized Submit/Finish outcomes without sleeps.

Review remediation round 1 added durable URL rejection, persistence boundary
routes, single-connection foreign keys, pinned controlled bundle/manifest
storage, source-loss scoring/reveal tests, idempotency replay/conflict/key
bounds, deadline and stale-revision checks, ownership checks, and barrier
tests for Finish plus Submit/Finish serialization. Round 2 moves idempotency
lookup ahead of status/deadline so the immutable receipt replays after both
finish and an elapsed deadline; rejects `sqlite:file::memory:`; boots the real
constructor from exactly one persisted bundle/manifest when sources are gone;
orders reveals by pinned question position; and rejects malformed manifest
coverage or changed manifest bytes for an existing bundle identity. The actual
focused test includes replay-after-deadline and catalog marker scanning.
