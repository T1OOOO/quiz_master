## Final behavior

- Public question, reveal, and error-envelope decoders are closed recursively.
  IDs, positive revisions, lowercase 64-hex hashes, required difficulty values,
  4–6 unique options, and nonempty strings are validated. Reveal accepts exactly
  one nonempty text, single-choice, or multiple-choice answer shape and rejects
  mixed, empty, duplicate-ID, unknown, and private forms.
- Normalized text uses a visible localized submit button. Widget tests enter text
  through the real text field, tap the control, and observe the normalized typed
  value. Revealed/submitting cards disable text and choice controls and suppress
  every answer callback.
- Choice controls expose their option text, stable ID, selected state, and enabled
  state through semantics. They participate in focus traversal and activate with
  Enter or Space; widget tests drive Tab plus the corresponding key and observe
  the emitted stable option ID.
- `QuizApp` owns one `GoRouter` for its state lifetime and disposes it with the
  app. Real navigation to the gallery now pushes history. Tests prove the same
  router instance, route, history, localized view, and join token survive locale
  and theme changes; back returns to the localized catalog.
- Material 3 light/dark/system theming, RU/EN localization, 4/5/6-option cards,
  narrow phone/large-text and wide-projector coverage, explicit reveal state,
  and the admission-only join boundary remain intact.
