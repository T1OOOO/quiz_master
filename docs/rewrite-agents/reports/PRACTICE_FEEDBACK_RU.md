Запрос: проверка одного варианта сразу по нажатию, пояснение в отдельной панели,
тёплые границы блоков по примеру Language Learner, общий вход в меню/домой/назад.

Использованы существующие серверные Score/BuildReveal и закреплённые версии
материалов. База расширена только таблицей practice_attempts. В режиме обычной
попытки ответы до завершения не раскрываются. Тренировка получает пояснение лишь
после принятого ответа, без возможности посмотреть будущие вопросы или чужую
попытку. Публичный каталог по-прежнему не содержит ключей и пояснений.

не отправляется заново. Один вариант проверяется нажатием; несколько вариантов
требуют подтверждения набора. Следующий вопрос открывается после чтения панели.

## Материалы: реальная граница выполненного

Исходная коллекция содержит 101 квиз, 3128 вопросов. Пояснения есть у всех,
но 497 текстов короче 55 символов: этот порог выделяет кандидатов на доработку,
а не доказывает ошибку. Некоторые просто повторяют ответ, например «Aran.».
На этом этапе подключены все исходные пояснения, но их независимая фактологическая
проверка и содержательная переработка НЕ завершены. Не публикуются автоматически
сгенерированные заглушки вида «ответ X правильный, потому что X».

Порядок последующей доработки: список слабых/неоднозначных текстов → небольшие
тематические партии → оригинальные источники → полноценное объяснение → отдельная
проверка → новая версия публикации. Старые манифесты попыток нельзя переписывать:
пояснения не входят в текущий controlled-bundle hash, поэтому публикация изменённого
манифеста обязана получать новую bundle_version.
