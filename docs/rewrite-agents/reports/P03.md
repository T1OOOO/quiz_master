## Entry-point findings and proposed contract

`Taskfile.yml` calls Bash `start.sh` and obsolete `web/` npm tasks; `web/` is absent. `start.sh` mutates dependencies (`npm install`, `go mod tidy`), kills port 8080, and launches `cmd/api`, whereas Compose exposes server/auth/storage at 8090/8092/8093. Docker builds Go 1.24 although `go.mod` requires 1.25. These are the same unresolved facts tracked by **quiz_master-qqx**; they prevent calling any existing entry point the rewrite's supported startup path.

Proposed Windows/local sequence, after `quiz_master-qqx` and P04/P07 approval: use a committed, rewrite-specific local Compose/Task target with pinned images; copy only the public example into an untracked `.env.local`; choose a unique project and resource prefix; then run `docker compose --project-name qm-local-<nonce> --env-file .env.local -f <approved-rewrite-compose> up --build`. Stop with `down --volumes` for that exact project. It must not invoke `start.sh`, mutate module locks, or use the existing shared `./data` bind mount. A direct Flutter Web session uses `cd flutter; flutter pub get; flutter run -d chrome` only after the backend endpoint contract is frozen.

Proposed CI order: restore pinned Go/Flutter caches; `go mod download`; `go test ./...`; `cd flutter; flutter pub get; flutter test; flutter build web`; then, on an Android-enabled runner, `flutter build apk --debug` (or the approved release artifact). Build/run tests must publish checksums and reports. This is proposed, not executed.

## Isolation, ports, and blockers

Reserved observed host ports are 8090 (server), 8092 (auth), 8093 (storage), 5432 (PostgreSQL overlay), 3000 (Grafana), 3100 (Loki), 3200 (Tempo), 4317/4318 (OTel), 9090 (Prometheus), and 9093 (Alertmanager). Every test run needs a unique Compose project, unique volume/database names, random host-port mappings where parallelism matters, an ephemeral quiz fixture directory, and teardown limited to its exact prefix. The current Compose files defeat this: fixed `container_name` values and `./data` bind mounts can collide. Its PostgreSQL overlay names databases but was **not** started; it is unverified as a Quiz test target.

Concrete blockers: unavailable Docker Desktop Linux daemon; missing Android command-line tools/emulator/device; missing `task` executable; absent legacy `web/`; Go 1.24/1.25 mismatch; mutable image tags (`latest`); fixed Compose names/shared data; and no approved rewrite CI manifest or Android signing authorization. Consequently, this is **not release readiness**.
