## Remediated executable evidence

`next/contracts/live-team-contract/v1` remains the separately versioned
extension of accepted `quiz-contract/v1`, pinned to base content hash
`5cc3275eb90dc71d58a5dc5d42be0fece52b727ead2bdf6ad9e7727a30df5f4e`.
P33F replaced the name-driven negative dispatcher with ten closed operation
input shapes. Every input field is read before the intended policy decision:
manual-code validation; admission; host/team authorization; captain claim and
transfer; answer/idempotency/close serialization; result access; replay; and
schema record mutation.

Each of the 33 fixtures declares `expected_error`. The checker accepts a
negative only when the real schema, manual or cross-record validator raises
that exact identifier. A different incidental error fails the fixture.
Schema cases copy a real positive event, apply their declared `set` or
`remove` mutation at the declared path, and run the same closed event schema
used for positives. The semantic operations are also run once with accepted
inputs before their negative fixtures. Missing and unknown-field meta-probes
pass for all ten operation shapes.

The poisoning meta-probe replaces every top-level input value except
`operation` with `IRRELEVANT`, reruns the dispatcher, and compares the raised
identifier to each unchanged `expected_error`. It reproduced zero of the 33
intended errors (observation hash
`4dc96d5a36bf2d56674d272cb8d4f3378f9ee9b49e1e025a7b97255310863b30`),
so fixture values are material rather than labels for hardcoded branches.

The prior fixes remain covered: closed audience/kind and result-access schema
branches; recursive presenter/host/reveal secrecy; rotation as an invitation
expiry trigger; closed policy retention fields; and direct wrong-audience,
public-share/full-session and nested-secret probes.

Not implemented here by design: production JSON Schema dialect validation,
cryptographic token generation, rate-limit persistence/throttling, database
transaction/unique-index proof, HTTP/WebSocket delivery/restart recovery, and
50-team load measurement. These remain assigned to P34, P35 and P38.
