# Карта знаний: план выполнения

Дата: 28 октября 2026. Beads: quiz_master-7rqa.
База: опубликованный исходный срез 8f0f3bfc, отдельная ветка codex/knowledge-map-20261028.

## Принятый интерфейс

Светлая карта: голубая вода, светлая суша, тонкие границы. Поиск сверху,
инструменты сбоку; постоянного нижнего меню нет. Нажатие открывает контекст
объекта. Флаги и подписи привязаны к странам; площадь показывается числом,
не цветом. Готовые геоданные и MapLibre заменяют ручную отрисовку только
после проверки прототипа. Существующий экран сохраняется на время проверки.

## Этапы и исполнители

1. Контракты, исходный срез и интеграция — ведущий Sol.
2. Геоданные и воспроизводимый сборщик — Terra 6.1, quiz_master-g0j3.
3. Отдельный Flutter-экран MapLibre, слои и контекст — Terra 6.1,
   quiz_master-93hf. Этот исполнитель единолично меняет pubspec и lock.
4. Достопримечательности — проверенные координаты и источники; неизвестные
   координаты не заменяем центром страны. Расширение после базового прототипа.
5. Проверки — отдельный агент; независимое ревью другим провайдером.
6. Перенос основного маршрута — после проверки Web и Android. Публикация
   требует отдельного пакета выпуска с прежними проверками резервной копии
   и отката; этот прототип сам по себе не является релизом.

## Контракт первого прототипа

Каталог assets/quizipedia/map_v2/:
- countries.geojson — FeatureCollection, Polygon/MultiPolygon.
- capitals.geojson — FeatureCollection, Point.
- country_labels.geojson — FeatureCollection, Point; флаг и название страны.
- water_labels.geojson — FeatureCollection, Point; подписи рек и озёр.
- waterways.geojson — FeatureCollection, LineString/MultiLineString,
  Polygon/MultiPolygon.
- landmarks.geojson — FeatureCollection, Point; допустима пустая коллекция
  с явным отчётом об отсутствии проверенных координат.
- manifest.json — схема qm-geography/v1, источники, хеши, числа объектов,
  ограничения охвата.

Координаты GeoJSON: WGS84, [долгота, широта], не нормализованные экранные x/y.
У объекта стабильный строковый feature.id; properties: id, name_ru, name_en,
kind (country/capital/river/lake/marine/landmark), country_id ISO2 там, где
связь известна. Для страны country_id обязателен. Моря и реки могут быть
международными. Названия и данные стран берём из существующих ресурсов.
Флаги берём из country_flag_images.json, не emoji. Неизвестное не выдумываем.

Генератор не зависит от сети при обычной сборке; получение новых исходников
явное, с URL/лицензией/хешем. Не грузим весь OSM или мировой тайловый архив.

Flutter: самостоятельный KnowledgeMapPage в lib/knowledge_map/,
конструктор const KnowledgeMapPage({super.key}); поддерживает RU/EN.
Ведущий добавляет отдельный маршрут /atlas/map-preview. Данные загружаются
из зафиксированных файлов. Ошибки загрузки и недоступный движок должны иметь
понятное состояние, повтор и путь назад. Тестам доступен подменяемый вид карты,
чтобы проверять управление без настоящего platform view.

## Приёмка

- Тесты порядка/диапазона координат, идентичности стран, ID, полигональных
  колец, детерминизма и контроля исходников.
- Тесты состояния слоёв, поиска, выбора/снятия выбора и восстановления после
  ошибки; площадь не становится заливкой.
- flutter analyze, целевые тесты, сборка Web с правильным API origin.
- Реальный запуск Web: масштабирование, перенос, флаги, выбор страны,
  контекст в пределах экрана, боковые инструменты на узком экране.
- Реальная проверка Android отдельно от Web; отсутствие устройства/SDK
  фиксируется как непрошедший этап, не как успешная проверка.
- Чистый ограниченный diff, независимое ревью, commit и push.

## Ограничения текущего прототипа

- Страны, физические сети рек и озёр используют данные 1:10 млн. Для обзора и подписей десять рек сохраняют геометрию 1:110 млн: полное сопоставление по Wikidata ID не установлено. Морские области сохраняют 1:110 млн.
- CYN/SOL не получают выдуманного соответствия стране; остаются исключёнными.
- Флаги с названиями сохраняют 219 прежних точек и добавляют 24 точки из подробного источника; перекрывающиеся подписи раскрываются при увеличении масштаба.
- Монтсеррат получил собственный контур и подпись. Столица — Брейдс, утверждённый в ноябре 2025 года; Плимут — бывшая столица.
- Контекст пока в компактной нижней карточке; привязка к месту касания ещё не реализована.
- Столица в карточке пока может показываться в исходном написании.
- 46 достопримечательностей существующего каталога имеют проверенные координаты Wikidata, отдельные ссылки на координаты и сведения, локальные фотографии и сохранённую атрибуцию.
- Web-движок MapLibre по умолчанию загружается с CDN; геоданные и стиль локальные.
- На момент проверки нет подключённого Android-устройства; flutter doctor
  сообщает о непринятых лицензиях Android SDK, текущий Java — JDK 17.
  Требования выбранного MapLibre к Android-сборке нужно согласовать отдельно.
