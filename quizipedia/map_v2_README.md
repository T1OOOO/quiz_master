# Knowledge map prototype data

Run `python scripts/build_knowledge_map.py` from the repository root. The builder reads only the pinned local files listed in the generated `map_v2/manifest.json`; it does not fetch data. A changed source hash fails the build before output is written. Run `python -m unittest discover -s scripts -p test_build_knowledge_map.py` for the contract checks.

Country and lake shapes use the Natural Earth 5.1.2 1:10m GeoJSON snapshots in `sources/map_v2` (public domain). The manifest records their versioned URLs and exact SHA-256 hashes. Country polygons retain the previous feature identities and names, with ISO2 `country_id`; additional shapes use identities and names from the existing country facts registry. The explicit TWN → TW and KOS → XK crosswalk is checked against that registry. Unmapped disputed shapes are not assigned to another country. Boundaries are generalized, and some countries or territories remain without shapes.

`country_labels.geojson` uses pinned Natural Earth cartographic label coordinates for the original shapes, then the first existing capital point for previously covered countries without shapes, and 1:10m label coordinates for additional shapes. Its `anchor_source` records the source. The existing Montserrat capital point is excluded because Natural Earth place ID 1159135121 identifies Plymouth, England; its country label instead uses the 1:10m Montserrat polygon source. The other 44 original capital fallbacks were checked by place ID and coordinates against Natural Earth populated places; its administrative names match their countries or territories, with French Guiana, Guadeloupe, and Martinique under France. The checked upstream GeoJSON had SHA-256 `9b8e3de09048ef00dfc70357dbb9fa324493f214b5e0ae4daf1aa79a8d10116b` at https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_populated_places.geojson. This audit source is not an offline build input.

The 63 waterways retain existing IDs and names. Lakes use 1:10m geometry matched by Wikidata ID; rivers and marine areas retain 1:110m geometry because the 1:10m river file lacks those IDs. River labels use an existing vertex on the longest available line; lake labels use a scanline point inside a polygon, accounting for holes. Marine areas do not receive point labels. Waterways have no inferred country relation.

`landmarks.geojson` copies the pinned, reviewed `quizipedia/landmark_locations.geojson` points and metadata, checking that IDs match the existing landmark catalog and that coordinate and image provenance is present. Coordinates are WGS84 longitude, latitude. Each landmark includes its coordinate source separately from its catalog source and image attribution. See that file for source details and the manifest for its hash.
