# Knowledge map prototype data

Run `python scripts/build_knowledge_map.py` from the repository root. The builder reads only the pinned local files listed in the generated `map_v2/manifest.json`; it does not fetch data. A changed source hash fails the build before output is written. Run `python -m unittest discover -s scripts -p test_build_knowledge_map.py` for the contract checks.

Country and lake shapes use the Natural Earth 5.1.2 1:10m GeoJSON snapshots in `sources/map_v2` (public domain). The manifest records their versioned URLs and exact SHA-256 hashes. Country polygons retain the previous feature identities and names, with ISO2 `country_id`; additional shapes use identities and names from the existing country facts registry. The explicit TWN → TW and KOS → XK crosswalk is checked against that registry. Unmapped disputed shapes are not assigned to another country. Boundaries are generalized, and some countries or territories remain without shapes.

`country_labels.geojson` uses pinned Natural Earth cartographic label coordinates for the original shapes, then the first existing capital point for previously covered countries without shapes, and 1:10m label coordinates for additional shapes. Its `anchor_source` records the source. Montserrat’s capital is Brades, confirmed in November 2025 ([UK PCGN](https://assets.publishing.service.gov.uk/media/69b1718558d4ef5adaf0e46a/UK_Overseas_Territories_Information_paper.pdf), Cabinet Decision 534/2025). Its capital point and country label use [GeoNames 7266440](https://www.geonames.org/7266440/brades.html), 16.79183, -62.21058 (CC BY 4.0). Plymouth is the former capital; Natural Earth place ID 1159135121 instead identifies Plymouth, England. The other 44 original capital fallbacks were checked by place ID and coordinates against Natural Earth populated places; its administrative names match their countries or territories, with French Guiana, Guadeloupe, and Martinique under France. The checked upstream GeoJSON had SHA-256 `9b8e3de09048ef00dfc70357dbb9fa324493f214b5e0ae4daf1aa79a8d10116b` at https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_populated_places.geojson. This audit source is not an offline build input.

The 63 waterways retain existing IDs and names. Lakes use 1:10m geometry matched by Wikidata ID. The Danube and Lena overview geometries use verified 1:10m segments; the remaining overview rivers and marine areas retain 1:110m geometry because a complete identity match was not established. River labels use an existing vertex on the longest available line; lake labels use a scanline point inside a polygon, accounting for holes. Marine areas do not receive point labels. Waterways have no inferred country relation.

`landmarks.geojson` copies the pinned, reviewed `quizipedia/landmark_locations.geojson` points and metadata, checking that IDs match the existing landmark catalog and that coordinate and image provenance is present. Coordinates are WGS84 longitude, latitude. Each landmark includes its coordinate source separately from its catalog source and image attribution. See that file for source details and the manifest for its hash.

`rivers_detail.geojson` is a separate physical layer containing all 3,739 Natural Earth 1:10m `River` and `River (Intermittent)` features. Lake centerlines and canals are excluded, so they do not introduce misleading lake or canal overlays. Its source-index IDs are stable for the pinned snapshot and do not claim Wikidata identities. Properties expose `kind`, Natural Earth `min_zoom`, and `intermittent`. For display, switch off only the overview river lines when enabling this layer at detailed zoom; continue displaying lake and marine geometry and the separate water labels. The source-recommended `min_zoom` can control feature visibility; the initial layer switch threshold is zoom 4.

`lakes_detail.geojson` is a separate physical layer containing all 1,355 polygon features in the pinned 1:10m lake source: Lake, Reservoir, and Alkaline Lake. Its IDs are stable source indices rather than Wikidata claims; `min_zoom` is copied from Natural Earth. Switch off the overview lake fill when displaying this layer at detailed zoom while keeping marine areas and water labels visible.
