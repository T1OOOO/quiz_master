# Knowledge map prototype data

Run `python scripts/build_knowledge_map.py` from the repository root. The builder reads only the pinned local files listed in `map_v2/manifest.json`; it does not fetch data. It rejects a changed source hash before writing output. Update the source pins deliberately when inputs are reviewed and changed. Run `python -m unittest discover -s scripts -p test_build_knowledge_map.py` to check the contract.

The three Natural Earth 1:110m waterway snapshots in `sources/map_v2` were acquired from the URLs in the generated manifest. Their SHA-256 values match those already recorded in the existing `waterways.json`; Natural Earth data is public domain. Country geometry is from the existing Natural Earth snapshot; capital positions are the existing Natural Earth points. The existing registry supplies country and matching Russian capital names. See the source entries and existing registry for provenance.

GeoJSON uses WGS84 longitude, latitude. Country feature IDs follow the existing catalog (ISO2 for registry countries, `ne-<adm0_a3>` for background shapes with an ISO2); `country_id` is the ISO2. The existing country facts registry validates the explicit TWN → TW and KOS → XK identity crosswalk. The disputed CYN and SOL shapes remain unmapped and are omitted without assigning them to another country. Natural Earth boundaries are generalized and some small islands and countries are absent at this scale. Capital points can exist without an associated country shape. Russian names fall back to the source name where the registry lacks an exact capital-name match. Waterways preserve existing Wikidata IDs and names, combine multiple source geometries under one ID, and do not infer a country. The landmark collection is empty until coordinates have been independently verified.
