# Материалы для подготовки к квизам

План и границы партий: [PLAN_RU.md](PLAN_RU.md). Приняты четыре вводных модуля и две углублённые главы: эволюция и чтение карт. Итоговые независимые решения сохранены в `reviews/final-*.md` и `reviews/wave2-*.md`.

Исходные статьи находятся в `modules/<тема>/article.md`; вопросы для самостоятельного решения — в `questions.candidate.json`; ответы, объяснения и источники — в отдельном `questions.key.json`. Обложки статей — в `assets/`; `image-briefs.json` хранит задания для отдельных изображений вопросов, а не готовые изображения.

Локальный читатель после сборки: `site/index.html`. Он работает как обычный файл в браузере, не требует API или базы данных. Это учебная самопроверка без рейтинга; сохранённые ответы доступны локально.

Сборка и проверка стандартным Python:

```
python study/build.py --write
python study/build.py --check
python study/check_reader.py
python -O study/check_reader.py
python study/build.py --write --flutter
python study/build.py --check --flutter
```

Сборщик проверяет структуру, ID, баланс ответов, число вопросов, длину объяснений, ссылки на записи источников, задания иллюстраций, наличие обложек и соответствие сохранённого результата исходникам. Фактическую точность независимо проверяют редакторы; структурная проверка не заменяет их вердикт.

Регрессионные браузерные сценарии и фактические границы проверки описаны в `reviews/browser-evidence.md`. Проверка структуры работает и при запуске Python с `-O`; некорректный шаблон останавливает сборку.

В Flutter материалы доступны через общее меню «Учебная библиотека» и маршрут `#/study`. Статьи имеют оглавление, источники и связанные квизы. Самопроверка перемешивает 20 вопросов, показывает объяснение ошибки поверх экрана, а верный ответ переключает через секунду с возможностью паузы. Она локальная и не влияет на рейтинг.

Локально готово: шесть статей, 120 проверенных вопросов и шесть иллюстраций статей. 56 следующих глав и отдельные изображения 120 вопросов остаются планом. Исходные ресурсы Flutter обновлены, но новая сборка и выкладка этой партии ещё не выполнены: на публичном сайте пока четыре учебных модуля / 80 вопросов. Разница между локальным результатом и релизом зафиксирована в `reviews/wave2-release.md`; предыдущая выкладка — в `reviews/release-evidence.md`.
