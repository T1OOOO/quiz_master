# Первая учебная партия

Читайте PLAN_RU.md и qm-quiz-writing. Автору выделены ровно два module-каталога. Используйте apply_patch. Не редактируйте git index, общие файлы, legacy quizzes или соседние черновики. Другие авторы работают рядом. Без дочерних агентов.

## module.json

Объект с полями `id`, `title`, `description`, `category`, `level`, `status` (`draft`), `reading_minutes_estimate` (целое), `objectives` (3–5 строк), `source_quiz_ids` (существующие ID тематических банков), `article` (`article.md`), `source_catalog` (массив объектов `id`, `title`, `url`, `accessed`, `evidence_status`, `scope`). Полученные источники действительно открыть и проверить. Не вставлять длинные цитаты. Дата доступа 2026-10-04.

## article.md

800–1200 русских слов ориентировочно, увлекательный связный текст для взрослого начинающего участника квизов. Минимум шесть осмысленных разделов. Начало с интересного вопроса; объяснения через примеры; таблица/схема; 3–5 распространённых путаниц; 5 коротких упражнений на вспоминание; руководство повторения; первичные ссылки рядом с утверждениями. Не просто списки и не энциклопедия имён. Факты, научные модели, мифологические версии и предложения явно различимы. Ссылки на иллюстрации вставьте `![описание](../../assets/<module-id>-hero.png)`; ведущий готовит эти файлы отдельно.

## questions.candidate.json

`{id:"study-<module-id>",title,description,category,questions:[{id:"study-<module-id>-001",type:"choice",text,options:[четыре строки]}]}`. Ровно 20 вопросов на модуль, новые знаниевые точки относительно релевантных `quizzes/`. Микс понимания, применения, узнавания и необычных фактов. Не задавайте просто «что написано в третьем абзаце». Один уверенный ответ, без спорных абсолютов.

## questions.key.json

`{pack_id:"study-<module-id>",accessed:"2026-10-04",records:[{id,correct_answer:0..3,explanation:"20–45 слов",difficulty:"начальный|средний|сложный",source_refs:[id из source_catalog],distractors:[три кратких пояснения почему остальные варианты неверны]}]}`. По пять ответов в каждой позиции, максимум два одинаковых подряд. Вытекание ответа в blind candidate запрещено. В статье ответы естественно встречаются: это учебная самопроверка.

## image-briefs.json

`{module_id,items:[{question_id,prompt,alt,purpose,status:"pending"}]}` — ровно по записи на каждый вопрос. Уникальные содержательные изображения без надписей и спойлеров ответа до выбора. Для фактических визуальных задач пометьте purpose `reference-required`, для иллюстраций `illustration`. Общее оформление: спокойная тёплая редакционная иллюстрация, сдержанные охра/оливковый/терракота, хорошее чтение маленьким превью. Не утверждайте, что изображение сгенерировано.

## Готовность

Сохраняйте каждый завершённый модуль сразу. Проверка стандартной Python-библиотекой допустима; никаких установок и тяжёлых сборок. Не ждите host offers/ресурсов: отдельное указание пользователя на немедленную работу и native coordination зафиксировано в PLAN. По возможности короткий READY в старый project agent_hub, но его недоступность не блокирует файлы. Верните список файлов, counts, проверенные источники и ограничения. Затем другой агент проверит материал.
