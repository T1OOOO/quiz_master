# Независимая проверка учебной партии

Beads `quiz_master-0oj`, корень C:/ap/quiz_master. Два отдельных reviewer-контекста, другие экземпляры агента, чем авторы. Reviewer A: природа/география; reviewer B: история/греческая мифология. Каждый владеет только своим файлом в `study/reviews/`, не меняет авторские файлы, git или released content. User requested immediate native agent work; don't wait in the old host queue. No children/heavy operations.

1. **Решить blind candidate.** Сначала прочитать только candidate каждого модуля, записать ответы и неоднозначности. Не читать key до решения всех20. Статья содержит учебные ответы, поэтому для чистого blind solve читать её после решения.
2. **Проверить ключ и источники.** Сверить каждую запись, реально открыть релевантные источники, проверить не только URL, но нужный факт в нём. Поисковый отрывок не считать открытой страницей. Указать точные ограничения и географические/авторские варианты. Сравнить с релевантными существующими quizzes для дублирования знания.
3. **Проверить статью.** Понятность для начинающего, интерес, объяснённые механизмы и примеры, отсутствие ложных обобщений, поддержка источниками, связь20вопросов с материалом, пригодность упражнений и дальнейшего чтения. Проверить факты таблиц и изображения как иллюстрации; сгенерированная картинка не доказательство.
4. **Оценить отдельно.** По5баллов: фактологическая точность, понятность, интерес, разнообразие вопросов, качество объяснений. Содержательное описание балла, без выдуманной измеренной сложности. Вердикт `ACCEPT`, `REVISE` или `REJECT` на модуль и конкретные номера, причины и минимальные исправления для вопросов. Нет принятия по одному структурному PASS.
5. **Сохранить отчёт.** Собственные blind ответы, источники с фактическим статусом доступа, обнаруженные дефекты, оценки, финальный вердикт. После авторских исправлений проверить только изменившиеся места и дополнить отчёт; не выдать старую проверку за новый ACCEPT.

Изображения статей уже сгенерированы в `study/assets/`. Индивидуальные80картинок вопросов пока представлены image-briefs. Эта партия — локальная учебная подготовка, а не утверждение о выкладке во Flutter/production или о готовности всех предыдущих планов.
